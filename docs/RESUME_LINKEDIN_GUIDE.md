## C. Professional LinkedIn Project Description

🚀 **New Project Showcase: Online Hobby & Skills Tracker on Cloud (SkillPulse)**

I recently completed building and deploying **SkillPulse**, a cloud-backed skills and habit tracking platform designed to solve motivation drop-off through structured goal milestones, practice telemetry, and community sharing.

Rather than just building a standard web app, my primary focus was demonstrating production-grade **Cloud Computing architectures and patterns**:

🔹 **Decoupled 3-Tier Architecture**: Decoupled React 18 single-page application communicating asynchronously with a containerized Python FastAPI microservice.  
🔹 **Cloud Object Storage**: Database records store lightweight metadata, while user achievement photos and proof documents reside in cloud object storage with cryptographically pre-signed URLs.  
🔹 **Multi-Tenant Security**: Stateless JWT bearer authentication, bcrypt password salting, role-based access control (RBAC), and sanitization pipelines preventing XSS and SQL injection.  
🔹 **Real-Time Telemetry & Streaks**: Algorithmic consecutive day streak calculations, automated milestone triggers upon logging practice sessions, and idempotent community engagement.  
🔹 **Testing & Containerization**: Multi-stage Dockerfile packaging frontend build and backend services into a single lightweight production container, backed by a 20-test automated pytest suite.
